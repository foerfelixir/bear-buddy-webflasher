Bear-Buddy listens on its own 38 kHz receiver (IO21) while you work. Every decoded frame — NEC, extended NEC or Samsung — scrolls “IR:” plus the code across the 5×5 matrix and lands here with its protocol and address. Button A clears the matrix, Button B replays the last code. Assigning a frame also switches that button to the protocol it arrived on, so a Samsung code drives the Samsung set that sent it.

    The image is built here in the browser from the codes on screen, never read back from the chip. A read-protected CH32V003 does not answer a flash read at all, so download the image and prove the remote works with your own programmer before trusting this link to write it. A Samsung button also needs the firmware inside this image: a remote still running the older NEC-only build rejects the new “IRC2” page and falls back to its factory NEC codes, so run Flash firmware once after picking a protocol.
